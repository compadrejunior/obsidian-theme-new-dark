# Components

Reusable controls and containers found across the interface.

| Page | What it changes |
| --- | --- |
| [Buttons](button.md) | Standard and call-to-action buttons in settings, dialogs, and plugin UIs. Button colors live in the Colors page under interactive colors. |
| [Checkboxes](checkbox.md) | Checkbox controls, and the text of completed tasks in task lists. |
| [Color input](color-input.md) | The color swatch shown by color pickers, for example in the Appearance settings. |
| [Dialogs](dialog.md) | Small confirmation dialogs, which are a lighter version of the modal. |
| [Dragging](dragging.md) | The visual feedback shown while you drag files or tabs. |
| [Dropdowns](dropdowns.md) | Dropdown menus and HTML `select` elements. |
| [Indentation guides](indentation-guides.md) | The vertical guide lines that show nesting depth, with separate indent widths for editing, reading, and source modes. |
| [Modals](modal.md) | Modal windows such as the settings window, and the dialogs built on top of them. |
| [Multi-select](multi-select.md) | Multi-select inputs, for example the list type of a property. |
| [Navigation](navigation.md) | Navigation items such as files and folders in the file explorer, and collapsible navigation headings such as linked mentions in the Backlinks and Outlinks plugins. |
| [Popovers](popover.md) | Hover popovers and file previews. |
| [Prompts](prompt.md) | Prompts such as the Quick switcher and the Command palette. |
| [Sliders](slider.md) | Slider controls in settings. |
| [Tabs](tabs.md) | Workspace tabs, including the container and the stacked tabs mode. |
| [Text input](text-input.md) | Text fields and search inputs: height, radius, font weight, and border width. |
| [Toggles](toggle.md) | On and off toggle switches in settings. |
