# Text input

**What it changes:** Text fields and search inputs: height, radius, font weight, and border width.

| Variable | Description |
| --- | --- |
| `--input-height` | Input height |
| `--input-radius` | Input radius |
| `--input-font-weight` | Input font weight |
| `--input-border-width` | Input border width |

Official reference: https://docs.obsidian.md/Reference/CSS+variables/Components/Text+input
