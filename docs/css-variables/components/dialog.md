# Dialogs

**What it changes:** Small confirmation dialogs, which are a lighter version of the modal.

| Variable | Description |
| --- | --- |
| `--dialog-width` | Dialog default width |
| `--dialog-max-width` | Dialog maximum width |
| `--dialog-max-height` | Dialog maximum height |

Official reference: https://docs.obsidian.md/Reference/CSS+variables/Components/Dialog
