# Color input

**What it changes:** The color swatch shown by color pickers, for example in the Appearance settings.

| Variable | Description |
| --- | --- |
| `--swatch-radius` | Color swatch radius |
| `--swatch-height` | Color swatch height |
| `--swatch-width` | Color swatch width |
| `--swatch-shadow` | Color swatch shadow |

Official reference: https://docs.obsidian.md/Reference/CSS+variables/Components/Color+input
