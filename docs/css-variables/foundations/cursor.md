# Cursor

**What it changes:** The mouse cursor over interactive elements and links. Obsidian follows operating system conventions, so interactive elements use the arrow rather than the pointer.

| Variable | Default value | Description |
| --- | --- | --- |
| `--cursor` | `default` | Cursor for interactive elements |
| `--cursor-link` | `pointer` | Cursor for links |

Official reference: https://docs.obsidian.md/Reference/CSS+variables/Foundations/Cursor
