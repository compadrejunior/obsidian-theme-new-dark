# Layers

**What it changes:** The stacking order (z-index) of overlapping interface parts: side docks, status bar, popovers, modals, notices, menus, tooltips, and dragged items.

| Variable | Default value |
| --- | --- |
| `--layer-cover` | `5` |
| `--layer-sidedock` | `10` |
| `--layer-status-bar` | `15` |
| `--layer-popover` | `30` |
| `--layer-slides` | `45` |
| `--layer-modal` | `50` |
| `--layer-notice` | `60` |
| `--layer-menu` | `65` |
| `--layer-tooltip` | `70` |
| `--layer-dragged-item` | `80` |

Official reference: https://docs.obsidian.md/Reference/CSS+variables/Foundations/Layers
