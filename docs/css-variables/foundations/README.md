# Foundations

Abstract values reused everywhere: colors, spacing, typography, borders, radiuses, layers, and icons.

| Page | What it changes |
| --- | --- |
| [Borders](borders.md) | The default border thickness reused by inputs, dividers, modals, tables, and most outlined elements. |
| [Colors](colors.md) | Almost every visible surface and text in the app. This is the most important page for a theme: the neutral base scale, the accent color, extended hues, surfaces, text, and interactive states all start here. |
| [Cursor](cursor.md) | The mouse cursor over interactive elements and links. Obsidian follows operating system conventions, so interactive elements use the arrow rather than the pointer. |
| [Icons](icons.md) | Size and stroke width of the Lucide icons used in the ribbon, sidebars, buttons, menus, and the editor. |
| [Layers](layers.md) | The stacking order (z-index) of overlapping interface parts: side docks, status bar, popovers, modals, notices, menus, tooltips, and dragged items. |
| [Radiuses](radiuses.md) | The corner rounding of buttons, inputs, modals, menus, and other containers. |
| [Spacing](spacing.md) | Padding, margins, gaps, and element dimensions throughout the interface, plus a few layout widths. |
| [Typography](typography.md) | Fonts, font sizes, weights, line heights, and paragraph spacing in both the editor and the interface. |
