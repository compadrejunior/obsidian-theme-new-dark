# Radiuses

**What it changes:** The corner rounding of buttons, inputs, modals, menus, and other containers.

| Variable | Default value |
| --- | --- |
| `--radius-s` | `4px` |
| `--radius-m` | `8px` |
| `--radius-l` | `12px` |
| `--radius-xl` | `16px` |

Official reference: https://docs.obsidian.md/Reference/CSS+variables/Foundations/Radiuses
