# Obsidian Publish

Variables created for Publish sites. Place them inside the `.published-container` selector.

| Page | What it changes |
| --- | --- |
| [Site components](site-components.md) | Titles of components such as the navigation, outline, backlinks, and graph on a published site. |
| [Site fonts](site-fonts.md) | Fonts and the base text size on a published site. |
| [Site footer](site-footer.md) | The footer of a published site. |
| [Site header](site-header.md) | The logo and header area of a published site. |
| [Site navigation](site-navigation.md) | The navigation tree on a published site. |
| [Site pages](site-pages.md) | The width and padding of published notes, and the page title. |
| [Site sidebars](site-sidebars.md) | The left and right sidebars on a published site. |
