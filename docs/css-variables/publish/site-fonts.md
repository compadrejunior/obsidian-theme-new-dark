# Site fonts

**What it changes:** Fonts and the base text size on a published site.

| Variable | Description |
| --- | --- |
| `--font-text-size` | Font size for page text |
| `--font-text-theme` | Font family for page text |
| `--font-monospace-theme` | Font family for code |
| `--font-interface-theme` | Font family for interface elements such as navigation |

| Variable | Description |
| --- | --- |
| `--page-title-font` | Font family for page titles |

Official reference: https://docs.obsidian.md/Reference/CSS+variables/Publish/Site+fonts
