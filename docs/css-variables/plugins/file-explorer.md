# File explorer

**What it changes:** The vault profile area at the bottom of the file explorer. This page lists the same variables as the Vault profile page, because the profile lives inside the file explorer pane. Items such as files and folders are styled through the Navigation page.

| Variable | Description |
| --- | --- |
| `--vault-profile-display` | `display` property for the vault profile |
| `--vault-profile-actions-display` | `display` property for the action buttons in the vault profile |
| `--vault-profile-font-size` | Font size |
| `--vault-profile-font-weight` | Font weight |
| `--vault-profile-color` | Text color |
| `--vault-profile-color-hover` | Text color (hover) |

Official reference: https://docs.obsidian.md/Reference/CSS+variables/Plugins/File+explorer
