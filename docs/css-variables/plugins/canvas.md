# Canvas

**What it changes:** The Canvas core plugin: the canvas background and dot pattern, card label color, and the six numbered card colors.

| Variable | Description |
| --- | --- |
| `--canvas-background` | Canvas background color |
| `--canvas-card-label-color` | Canvas card label text color |
| `--canvas-dot-pattern` | Canvas dot pattern color |
| `--canvas-color-1` | Canvas card color 1, `var(--color-red)` by default |
| `--canvas-color-2` | Canvas card color 2, `var(--color-orange)` by default |
| `--canvas-color-3` | Canvas card color 3, `var(--color-yellow)` by default |
| `--canvas-color-4` | Canvas card color 4, `var(--color-green)` by default |
| `--canvas-color-5` | Canvas card color 5, `var(--color-cyan)` by default |
| `--canvas-color-6` | Canvas card color 6, `var(--color-purple)` by default |

Official reference: https://docs.obsidian.md/Reference/CSS+variables/Plugins/Canvas
