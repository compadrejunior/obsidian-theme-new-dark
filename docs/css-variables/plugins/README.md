# Plugins

Interface elements that belong to core plugins.

| Page | What it changes |
| --- | --- |
| [Canvas](canvas.md) | The Canvas core plugin: the canvas background and dot pattern, card label color, and the six numbered card colors. |
| [File explorer](file-explorer.md) | The vault profile area at the bottom of the file explorer. This page lists the same variables as the Vault profile page, because the profile lives inside the file explorer pane. Items such as files and folders are styled through the Navigation page. |
| [Graph view](graph.md) | The Graph view core plugin: colors of nodes (including unresolved, focused, tag, and attachment nodes), lines, and labels, plus the controls width. |
| [Search](search.md) | The Search core plugin: the clear button and search icon, and the result background. |
| [Sync](sync.md) | The Obsidian Sync plugin: the avatar colors that identify collaborators. |
