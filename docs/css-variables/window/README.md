# Window

The application chrome around the content.

| Page | What it changes |
| --- | --- |
| [Dividers](divider.md) | The draggable dividers and resize handles between sidebars, tabs, and split panes. |
| [Ribbon](ribbon.md) | The vertical icon bar at the edge of the window. |
| [Scrollbars](scrollbar.md) | The custom scrollbars Obsidian draws. They only appear on Windows and Linux, while macOS keeps its native scrollbars. |
| [Sidebar](sidebar.md) | The left and right sidebars: text size of Markdown files and tab text display. |
| [Status bar](status-bar.md) | The bar at the bottom edge of the window. |
| [Vault profile](vault-profile.md) | The vault name and action buttons at the bottom of the left sidebar. |
| [Window frame](window-frame.md) | The titlebar and the default height of frame elements. |
| [Workspace](workspace.md) | The translucent background of the workspace area that holds the tabs and panes. |
