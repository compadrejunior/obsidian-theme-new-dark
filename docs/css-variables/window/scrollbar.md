# Scrollbars

**What it changes:** The custom scrollbars Obsidian draws. They only appear on Windows and Linux, while macOS keeps its native scrollbars.

| Variable | Description |
| --- | --- |
| `--scrollbar-bg` | Scrollbar background color |
| `--scrollbar-thumb-bg` | Scrollbar thumb background color |
| `--scrollbar-active-thumb-bg` | Scrollbar thumb background color (active) |

Official reference: https://docs.obsidian.md/Reference/CSS+variables/Window/Scrollbar
