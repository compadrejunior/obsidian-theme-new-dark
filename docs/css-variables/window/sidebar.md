# Sidebar

**What it changes:** The left and right sidebars: text size of Markdown files and tab text display.

| Variable | Description |
| --- | --- |
| `--sidebar-markdown-font-size` | Font size for Markdown files in sidebars |
| `--sidebar-tab-text-display` | `display` property for tab text in sidebars |

Official reference: https://docs.obsidian.md/Reference/CSS+variables/Window/Sidebar
