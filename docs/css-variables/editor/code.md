# Code

**What it changes:** Inline code, code blocks, and syntax highlighting colors.

Obsidian uses two different syntax highlighting libraries, one in editing view and one in reading view, so the two may not match exactly.

| Variable | Description |
| --- | --- |
| `--code-background` | Code background color |
| `--code-white-space` | Code `white-space` |
| `--code-size` | Code font size |

## Syntax highlighting

| Variable | Description |
| --- | --- |
| `--code-normal` | Non-highlighted syntax |
| `--code-comment` | Comments |
| `--code-function` | Functions |
| `--code-important` | Important, regex |
| `--code-keyword` | Keywords |
| `--code-operator` | Operators |
| `--code-property` | Properties |
| `--code-punctuation` | Punctuation |
| `--code-string` | Strings |
| `--code-tag` | Tags, symbols, constants |
| `--code-value` | Values |

Official reference: https://docs.obsidian.md/Reference/CSS+variables/Editor/Code
