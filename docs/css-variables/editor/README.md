# Editor

Content types shown while editing and reading notes.

| Page | What it changes |
| --- | --- |
| [Bases](bases.md) | The Bases core plugin: the container, the table view, and the cards view. |
| [Blocks](block.md) | Rendered blocks in Live Preview. |
| [Blockquotes](blockquote.md) | Quoted text introduced with `>`. |
| [Callouts](callout.md) | Callout boxes, including the icon and color of each callout type. |
| [Code](code.md) | Inline code, code blocks, and syntax highlighting colors. |
| [Embeds](embed.md) | Embedded notes and files, such as `![[Note]]`. |
| [File](file.md) | The open note itself: line width, margins, and the file header. |
| [Footnotes](footnote.md) | The text size of footnotes. |
| [Headings](headings.md) | Heading levels H1 to H6 in the editor and in reading view: size, weight, color, font, and line height. |
| [Horizontal rules](horizontal-rule.md) | Horizontal rules written as `---` in a note. |
| [Inline title](inline-title.md) | The note title displayed above the content when the inline title option is on. |
| [Links](link.md) | The three link types: resolved internal links to an existing note, unresolved internal links to a note that does not exist, and external links to a URL. |
| [Lists](list.md) | Ordered and unordered lists: indentation, spacing, marker colors, bullet shape, and numbering style. |
| [Properties](properties.md) | The properties (YAML frontmatter) editor, both the container as a whole and each individual property. |
| [Tables](table.md) | Markdown tables: borders, header cells, rows, alternating backgrounds, columns, and text. |
| [Tags](tag.md) | Tags such as `#idea`: color, background, border, padding, and radius. |
