# CSS variables reference

Obsidian exposes hundreds of CSS variables. A theme works by overriding these variables, which is more stable than writing selectors, because Obsidian can rename its internal classes between releases.

Every page lists a **What it changes** summary, followed by tables of variables with their default values or descriptions. The reference holds 60 pages grouped into six areas.

| Area | Contents |
| --- | --- |
| [Foundations](foundations/README.md) | Colors, typography, spacing, borders, radiuses, layers, icons, cursor. |
| [Components](components/README.md) | Buttons, checkboxes, dialogs, modals, dropdowns, inputs, navigation, tabs, toggles, and other controls. |
| [Editor](editor/README.md) | Headings, links, tags, callouts, code, tables, lists, properties, embeds, and other note content. |
| [Plugins](plugins/README.md) | Canvas, file explorer, graph view, search, and Sync. |
| [Window](window/README.md) | Ribbon, sidebar, status bar, scrollbars, dividers, window frame, workspace, and vault profile. |
| [Obsidian Publish](publish/README.md) | Variables specific to published sites. |

To look up a single variable by name, use the [variable index](../variable-index.md).
