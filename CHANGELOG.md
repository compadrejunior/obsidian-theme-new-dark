# Changelog

All notable changes to New Dark are documented here. The project follows [Semantic Versioning](https://semver.org/), and each version number matches its Git tag and the `version` in `manifest.json`.

## [Unreleased]

### Added

- Dark palette modeled on VS Code Dark Modern, and a light palette modeled on Light Modern.
- Hairline 1px borders, small rounded corners, and flat window chrome for the titlebar, ribbon, tabs, sidebars, and status bar.
- VS Code syntax colors for code blocks.
- Accent colored headings and bold text.
- Wide reading column at 95% of the pane width.
- Tables that fill the pane and wrap long cells.
- Centered Mermaid diagrams that escape the reading column when they are wide.
- Hidden gutter line numbers in Live Preview.
- Print styles for PDF export, including a `page-break` helper class.
- User documentation: README, user guide, and reference of Obsidian CSS variables.
